# References

Every source cited in the book, with a link to its official copy and the
terms under which it can be read. The PDFs themselves are not kept in this
repository: a public repository redistributes what it contains, and most of
these works may be read freely but not redistributed.

**Rule for this file.** A link and a licence are entered only after the
page has been opened and the entry compared with it. An entry marked
"not yet checked" carries the bibliographic data used in the book, from
memory, and no link.

**Local copies.** Put your own copies in `references/pdf/`. That folder is
ignored by git.
