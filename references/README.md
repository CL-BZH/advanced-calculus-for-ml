# References

Sources cited in the book, with a link to the official copy and the terms
under which it can be read. The PDFs themselves are not kept in this
repository: a public repository redistributes what it contains, and most of
these works may be read freely but not redistributed.

**Rule for this file.** An entry is added only after its official page
has been opened and the entry compared with it. Sources cited in the book
that have not been through this check yet are not listed.

**Local copies.** Put your own copies in `references/pdf/`. That folder is
ignored by git.
